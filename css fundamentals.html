Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to style HTML elements and improve the appearance of webpages.

CSS Fundamentals

Selectors: Target HTML elements.

Colors: Change text and background colors.

Fonts: Control text appearance.

Spacing: Use margin and padding.

Borders: Add outlines around elements.
